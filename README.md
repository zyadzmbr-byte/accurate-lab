# 🧪 Accurate Lab | معمل أكيوريت للتحاليل الطبية

البوابة الإلكترونية الشاملة والمتكاملة لموظفي وإدارة **معمل أكيوريت للتحاليل الطبية (Accurate Lab)**.
تم تصميم النظام ليعمل بكفاءة فائقة على الهواتف المحمولة وكافة الأجهزة، مع مزامنة لحظية عبر خوادم **Firebase** ورفع مباشر للملفات الطبية عبر **Cloudinary**.

---

## 🌟 مميزات النظام

### 👨‍⚕️ واجهة الموظفين (4 صفحات أساسية)
1. **⏱️ صفحة تسجيل الحضور والانصراف**:
   - ساعة حية بالثواني والتاريخ المحلي باللغة العربية.
   - 4 حركات تسجيل:
     - ☀️ تسجيل دخول صباحي
     - ☀️ تسجيل خروج صباحي
     - 🌙 تسجيل دخول مسائي
     - 🌙 تسجيل خروج مسائي
   - إرسال فوري ولحظي لتقرير الحركة إلى لوحة تحكم الإدارة متضمناً: **اسم الموظف، الكود الرباعي، والفرع / المنطقة**.
   - كروت تفاعلية توضح حالة تسجيل الحركات اليومية مع سجل تاريخي بكافة الحركات.

2. **🎁 صفحة المكافآت والخصومات**:
   - إحصائيات مالية دقيقة بالجنيه المصري (إجمالي المكافآت، إجمالي الخصومات، والصافي).
   - جدول يوضح كافة العمليات المالية وسبب المكافأة أو الخصم وتاريخ تسجيلها.

3. **📦 صفحة طلب المستلزمات الطبية**:
   - كتالوج لجميع المستلزمات المتاحة بالمعمل والمضافة من قبل الإدارة مع صورها ووحداتها.
   - إمكانية طلب مستلزم مع تحديد الكمية والملاحظات.
   - متابعة لحظية لحالة صرف الطلبات (`قيد المراجعة` / `تم الصرف والتجهيز ✅`).

4. **🏖️ صفحة طلب إجازة**:
   - تقديم طلب إجازة مع تحديد: عدد الأيام، تاريخ البدء، نوع الإجازة، والسبب.
   - إمكانية إرفاق تقرير طبي أو عذر مرفوع مباشرة إلى **Cloudinary** مع شريط تقدم مئوي.
   - استلام رد الإدارة بالموافقة أو الرفض مع الملاحظات لحظياً.

  - 💰 **إرسال مكافأة أو خصم**: اختيار الموظف بكوده، وتحديد المبلغ بالجنيه المصري وسبب الإجراء، مع إمكانية حذف السجلات.
  - ⏱️ **سجل الحضور المباشر**: بث حي ومباشر لكافة حركات الحضور والانصراف الواردة فوراً من الفروع، مع فلترة بالبحث والتاريخ وخيارات التصدير إلى Excel والطباعة.

### ✨ لمسات فنية وتجربة مستخدم
- **انميشن أنبوب التحاليل (0.5 ثانية)**: عند الانتقال بين الصفحات يظهر أنبوب تحاليل مخبري تخرج منه فقاقيع بيضاء صاعدة على شاشة بلون سماوي لمدة نصف ثانية ثم تختفي بسلاسة.
- **تبديل المظهر (فاتح / داكن)**: زر في الهيدر يُحول الموقع بالكامل من الفواتح إلى الغوامق مع حفظ تفضيل المستخدم في المتصفح.
- **تطبيق PWA مثبت**: جاهز للتثبيت كتطبيق مستقل على الشاشة الرئيسية للهواتف الذكية عبر `manifest.json`.
- **مؤثرات صوتية هادئة**: أصوات مستوحاة من الأجهزة الطبية وفقاقيع المعامل تعمل عبر Web Audio API بدون أي ملفات خارجية.

## 🚀 طريقة التشغيل والرفع على GitHub Pages

### 1. التشغيل المحلي:
يمكنك فتح الموقع مباشرة بالنقر المزدوج على ملف `index.html` في أي متصفح، وسيعمل بكامل وظائفه.

### 2. التفعيل على GitHub Pages:
1. ارفع كافة ملفات المجلد إلى مستودعك (Repository) على GitHub.
2. توجه إلى **Settings** الخاصة بالمستودع على GitHub.
3. من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - **Source**: اختر `Deploy from a branch`.
   - **Branch**: اختر `main` (أو `master`) والمجلد `/ (root)`.
   - اضغط **Save**.
5. خلال دقيقة واحدة سيكون موقعك متاحاً ويعمل بكامل تنسيقاته بدون أي تشوه بفضل ملفات `.nojekyll` و `.gitattributes` والتنسيقات المدمجة.
